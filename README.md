# Personal Information Manager

## Project Description
This is my first Python project! It's a program that stores, processes, and displays personal information using variables, input validation, calculations, and string formatting.

## What I Learned
1. **Variables:** How to store different types of data (strings, integers).
2. **Input/Output:** Getting user input dynamically and displaying formatted results.
3. **String Formatting:** Using f-strings and string methods (like `.strip()` and `.title()`).
4. **Error Handling & Validation:** Using `while` loops to check for empty inputs.
